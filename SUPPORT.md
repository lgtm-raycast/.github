# Support

Start with the affected extension's README and maintenance policy. For Brew, see
[installation and development](https://github.com/lgtm-raycast/brew) and
[upstream maintenance](https://github.com/lgtm-raycast/brew/blob/main/docs/maintenance.md).

Search existing issues before opening a bug report or feature request in the affected repository. Include macOS,
Raycast and extension versions, the downstream commit/release, exact reproduction steps and sanitized logs.
Shared defaults problems belong in [this repository's issues](https://github.com/lgtm-raycast/.github/issues).

These are independent downstreams. Report downstream behavior here first; link upstream issues where relevant.
Feature and design changes need maintainer assessment. Users install/update their own local extension checkouts.
Security findings use [private reporting](SECURITY.md). Support depends on maintainer availability.
