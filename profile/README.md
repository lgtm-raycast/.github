# LGTM Raycast

Independently maintained forks of [Raycast extensions](https://github.com/raycast/extensions), shaped around
[LGTM HQ](https://github.com/lgtm-hq) tooling and standards. Each extension has its own public repository.

Start with [Brew](https://github.com/lgtm-raycast/brew), originally created by
[nhojb](https://github.com/nhojb) and the [Raycast community](https://github.com/raycast/extensions).
Original authors, licenses and upstream history remain credited in each repository.

Extensions are installed locally by their users. Feature and design adoption is assessed explicitly;
maintenance automation reports upstream changes and follows each repository's documented policy.
